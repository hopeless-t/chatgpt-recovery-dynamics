Evidence Court

その主張、
証拠あるにゃ？

パケニャ検察が勢いで断言し、裁判長がEvidence boundaryで殴る法廷にゃ。下の選択肢はゲーム。判決文はこのrepoの証拠分類に合わせてある。

法廷原則： Observed / Recomputed / Supported model / Simulation / Proposal / Unknown を別物として扱う。ラベルを跨ぐには証拠が要る。
CASE 429-01
「429が出た。つまり1分あたり固定N回のrate limitにゃ！」
判決：NOT ESTABLISHED。429はclient-visible status。counting scopeや内部limit値はstatusだけでは決まらない。
CASE TRACE-108
「公開traceでは108 pair中、48 Accessible / 60 Blocked / mixed 0だったにゃ。」
判決：ADMISSIBLE。これは公開derivative traceから再計算されるrepo内の定量結果。
CASE SVG-404
「綺麗なnetwork図がある。つまりOpenAI内部構造はこうにゃ！」
判決：異議あり。 Visualization ≠ Evidence。図は設計・説明・仮説を表現できるが、内部topologyの観測証拠にはならない。
CASE SIM-090
「ρ=0.90のlocal simulatorでretry amplificationが18.54×→3.98×になったにゃ。」
判決：SIMULATION。設計比較には使えるが、OpenAI productionの実測値ではない。
CASE E-008
「このcapture内では、B後の最初のAccessible excursionは通常のHと分ける価値があるにゃ。」
判決：SUPPORTED WITHIN CAPTURE。B→E→Bが8/8、history-aware modelもA/Bより良い。ただし一般法則とは別。
