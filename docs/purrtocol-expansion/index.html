一番大事な結果

ただし、笑いのために因果を捏造してはいけない。measurement-associated repository backactionとして別cohortに隔離する。

複利baseline

dP/dt = rP P(t) = P₀ exp(rt) T₂ = ln(2)/r

primary 10イベントでは倍加時間≈3.758h。observer-inclusive 22イベントでは≈2.803h。どちらも短いcurated windowの記述fitで、forecastではない。

Hawkes過程

λ(t) = μ + Σ α exp[-β(t-tᵢ)] n = α/β primary: n≈0.85 → subcritical inclusive: n≈1.00 → near-critical

同じ記述grid fitでの比較。一般的な「猫は観測すると増える」法則は確立していない。

観測者効果みたいな何か

測定装置を作ったら、測定対象が12個増えたにゃ。
分析・論文・設定資料集・導線・machine-readable surface・Wiki・CIを実装した結果、183秒のmeasurement-associated burstが生まれた。
checkpoint = ec25244… primary = 10 events observer_effect = +12 events / 183 s inclusive = 22 events

checkpointは固定。それ以降の「猫を数えるために増えた猫資料」は同じcheckpointへ再帰的に足さない。さもないと永久に猫を数えるための猫が増える。
