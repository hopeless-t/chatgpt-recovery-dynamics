一番大事な結果

発想空間は暴走して見えるが、現時点の実装commit系列から supercritical growth は証明できていない。
笑いのために branching ratio を盛ってはいけない。脚注はパケニャより賢くあるべきにゃ。

複利baseline

dP/dt = rP P(t) = P₀ exp(rt) T₂ = ln(2)/r

選択された10イベントの記述fitでは r≈0.1844/hour、倍加時間≈3.758h。ただし短く手動選択されたburst観測窓なのでforecastではない。

隣接接点が増えると

C(P) = P(P-1)/2 dP/dt = rP + bP² t* = (1/r) ln(1 + r/(bP₀))

b>0ならtoy model上は有限時間特異点が出る。ただしbは未推定。地球が猫で埋まる時刻の実証値ではない。

Hawkes過程

λ(t) = μ + Σ α exp[-β(t-tᵢ)] n = α/β

現在の記述的grid fitは n≈0.85、subcritical。手動annotationの隣接アイデア発生数は平均3.3/eventだが、これはHawkes branching ratioではない。

観測hazard

h(P)=h₀+sP S(t)=exp[-h₀t-(sP₀/r)(exp(rt)-1)]

パケニャsurfaceが増えるほど観測確率が上がるscenario。Sam/Tiboの実観測hazardは計測していない。
