存在するのか。

パケニャは「かわいい猫」より先に、復旧システムで人間と機械がやらかしがちな誤りを、安全に演じるためのanthropomorphic error modelとして定義される。

Canonical production rule: ジョークは雑でもよい。脚注は雑であってはならない。

State-machine avatar

B/E/Hを表情と行動に変換する。

Negative-example generator

duplicate retry、UNKNOWN再実行、Visualization=Evidenceなどを自らやらかして教材化する。

Mnemonic compressor

長い設計原則を「はい429ストップ！！」へ圧縮する。

Epistemic guardrail

Observed / inferred / simulated / proposed / unknownを混ぜない。

Human-factors proxy

反応がないともう一回押したくなる人間の衝動を猫が代演する。

Brand anchor

長い研究名より一匹の猫の方が記憶に残る。これは証拠ではない。

Canonical body language

B / Blocked → red / ears down E / Recovering → amber / cautious step H / Healthy → green / one stable snapshot carried home Observe → tiny cyan packet UNKNOWN → do not run

禁止設定
