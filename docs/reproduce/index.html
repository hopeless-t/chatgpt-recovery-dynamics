One minute.
Public data only.

These commands recompute from the sanitized derivative files in the repository. They do not contact ChatGPT or OpenAI production services.

1 · Clone
git clone https://github.com/hopeless-t/chatgpt-recovery-dynamics.git
cd chatgpt-recovery-dynamics
2 · Recompute the core public analysis
python3 scripts/analyze_public_data.py

Expected core invariants include 108 paired observations: 48 Accessible, 60 Blocked, 0 mixed; P(B next | B) ≈ 0.8621; and the published cycle-law coefficients.

3 · Recompute transition biopsy
python3 scripts/analyze_transition_biopsy.py
python3 scripts/compete_transition_models.py

Expected: reentry 8/8 → Blocked in this capture, and the history-aware H/E/B model outperforms the simpler A/B model within this dataset.

4 · Deep validation
python3 scripts/deep_validate_trace.py --permutations 5000
python3 scripts/validate_model_generalization.py
5 · Local simulations
python3 scripts/monte_carlo_recovery.py --trials 5000 --bootstrap-trials 10000
python3 scripts/simulate_transport_recovery_paths.py --trials 5000
python3 scripts/simulate_server_congestion.py --trials 12
Do not point these ideas at production as a load test. The repo's congestion experiments are local simulations. Raw authenticated HAR files are intentionally not published.
