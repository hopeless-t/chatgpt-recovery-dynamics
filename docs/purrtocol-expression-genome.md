# Purrtocol Expression Genome / 発現ゲノム

Status: **simulation-derived proposed parameters — not rendered assets**

The Expression Genome connects C1 Ecology → Graphic Evolution → Second Light without collapsing those layers into one opaque generator.

```text
C1 ecology history
  -> Graphic Manifest
  -> Expression Genome
  -> Second Light implementation target
  -> later rendered specimen
```

The layer converts categorical phenotype and presentation history into bounded numeric expression parameters for:

- body/head roundness;
- ear asymmetry and tail arc;
- breathing, tail secondary motion, step amplitude, timing;
- surface roughness bias;
- presentation regime, camera and lighting grammar.

Stable per-organism jitter comes from the organism ID hash, so descendants can remain individually distinguishable without nondeterministic randomness.

## Selection law

A simulated survivor may target the Second Light generator. An extinction exemplar is retained for Museum projection only and is not breeding-eligible.

```text
survives = true  -> breeding_eligible = true
survives = false -> museum-extinction-memorial-only
```

Projection quality cannot resurrect an invalid/extinct lineage by itself.

## Why this layer exists

The generator should not become an uninspectable soup of ecology rules, visual taste, rendering code and human-response guesses. Expression Genome is the inspectable projection boundary between simulated history and implementation parameters.

It also lets later renderers compete against the same expression genome. A Blender renderer, a tiny procedural GLB renderer, or a future canonical-web runtime renderer can consume the same bounded intent while being evaluated separately.

## World laws

```text
Expression != rendered asset
Simulation != Evidence
Visualization != Evidence
Generated variant != Canon
UNKNOWN != SUCCESS
Technical quality != humor
```

Human humor, comprehension, replay value and propagation are never filled in by the compiler. They remain `UNKNOWN` until an actual observation lane exists.
