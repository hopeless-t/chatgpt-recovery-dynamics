429教養講座

知っただけで「ほう……429ですか」と急に賢そうな顔ができる、役に立つような立たないような雑学集にゃ。

① 429って何にゃ？

「おまえちょっと来すぎにゃ。少し待てにゃ。」のHTTP版にゃ。

真面目な脚注： HTTP 429は Too Many Requests。RFC 6585で追加され、一定時間内に多数のrequestを送った、いわゆるrate limiting状態を表す。仕様は「誰をどう数えるか」を固定していない。

② 429は昔からいたの？

意外と若いにゃ。HTTP界の古代生物ではないにゃ。

真面目な脚注： RFC 6585は2012年4月発行。429のほか、428、431、511も追加した。

③ Retry-Afterって何にゃ？

鯖からの「今じゃないにゃ」。読めるなら読めにゃ。

真面目な脚注： 429 responseはRetry-Afterを含めてもよい。Retry-Afterは「あと何秒」またはHTTP-dateで待ち時間を表現できる。

④ 429なら全部同じrate limit？

ぜんぜん決まってないにゃ。「429だった」だけで内部事情を透視するなにゃ。

真面目な脚注： RFC 6585はrequestの数え方やuserの識別方法を規定していない。resource単位、server全体、複数server、認証情報、cookieなど様々な実装があり得る。

⑤ 429はキャッシュしていい？

「昔429だったから今も429にゃ！」を保存するなにゃ。

真面目な脚注： RFC 6585では429 responseをcacheに保存してはならないと規定している。

⑥ 429は数学でも出るにゃ

なんと429はカタラン数にゃ。急に数学者っぽい空気を出せるにゃ。

C₇ = (1 / 8) × binom(14, 7) = 429
真面目な脚注： 429は第7カタラン数 C₇。例えば8個の要素を二項演算で完全に括弧付けする方法の数などに現れる。

⑦ カタラン数って何を数えるにゃ？

木とか括弧とか山道とか、「なんで同じ数になるにゃ？」という物をやたら数える数列にゃ。

真面目な脚注： カタラン数は二分木、正しい括弧列、凸多角形の三角形分割など、多数の組合せ構造に現れる。

⑧ 429を見たら連打？

監督「はい429ストップ！！！」にゃ。

真面目な脚注： このrepoの設計方針は、429やambiguous transport failureを「もっと押す理由」にしない。server-directed spacing、single-flight、cheap observation、re-observationを優先する。

⑨ 429 ≠ root cause

症状名を見ただけで犯人当てゲームを始めるなにゃ。

真面目な脚注： client-visible HTTP statusはbackend root causeを一意に決めない。本研究もOpenAI内部の原因やproduction topologyを特定したとは主張しない。
パケニャ検定：「429を見た。つまり1分にN回の固定limitだ」と断言してよい？

だめにゃｗ 429仕様はcounting scopeもuser identificationも固定していないにゃ。観測できたことと内部実装を分けるにゃ。
