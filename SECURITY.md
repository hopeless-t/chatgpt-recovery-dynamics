# Security policy

This repository analyzes client-observed reliability behavior. It is not a place to publish private session material, identifying endpoint data, or private conversation content.

## Reporting

If you find sensitive data accidentally committed to this repository, do not quote or repost it in a public issue. Contact the repository owner privately through an appropriate GitHub contact channel.

## HAR files

Do not upload raw HAR files.

HAR captures can contain private session and account material even when the visible browser session appears harmless.
