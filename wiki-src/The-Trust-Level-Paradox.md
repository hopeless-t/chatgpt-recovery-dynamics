# The Trust-Level Paradox

This page records a project-history anecdote from the OpenAI Developer
Community.

## Timeline reported by the author

The author reports the following sequence:

~~~text
1. Posted a feature-improvement suggestion about the iOS ChatGPT app.
2. Shortly afterward, the community account was placed on temporary hold /
   suspension.
3. Later, the community system sent a message congratulating the account for
   reading activity and promoting it up a trust level.
4. That same interface also displayed a related message:
   "Account temporarily on hold."
~~~

The English UI additionally encouraged the user to fill out the profile or
start a new topic.

## What is actually being recorded

This repository records the **temporal sequence**:

~~~text
iOS ChatGPT feature-improvement post
        ↓
temporary account hold shortly afterward
        ↓
later trust-level promotion / participation encouragement
        ↓
"Account temporarily on hold" still visible in related messages
~~~

It does **not** claim that the feature-improvement post caused the account hold.

No moderation rationale, internal enforcement mechanism, or causal relationship
has been independently established here.

## Why it is preserved

The screenshot is amusing, but it is also a useful interface-state anecdote:

~~~text
engagement / trust subsystem:
  trust level increased
  participation encouraged

account-control subsystem:
  temporary hold / suspension
~~~

Apparently contradictory states can therefore be presented in the same user
interface without implying that they share one backend mechanism.

Classification:

~~~text
source:
  contemporaneous author report + community UI screenshot

evidence class:
  project archaeology / UI-state dissociation anecdote

included in the 108-pair ChatGPT recovery dataset:
  no

evidence of a shared backend mechanism:
  no

evidence that the iOS feature-improvement post caused suspension:
  no
~~~

> **Temporal adjacency != causation.**

> **UI-state anecdote != shared backend mechanism.**
