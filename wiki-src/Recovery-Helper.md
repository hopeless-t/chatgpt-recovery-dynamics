# Recovery Helper

A bilingual Japanese / English troubleshooting service for affected users.

## Live

[Open Recovery Helper](https://hopeless-t.github.io/chatgpt-recovery-dynamics/recovery-helper/)

## Privacy contract

- no automatic ChatGPT/OpenAI API calls
- no fetch/WebSocket/EventSource/sendBeacon
- no cookies
- no localStorage/sessionStorage
- no telemetry
- no external JavaScript
- support memo generation stays in the browser

Official OpenAI guidance and research-derived suggestions are visibly separated.

The Helper is intentionally designed so troubleshooting itself does not create unnecessary retry traffic.
